# Propane Absorption Tutorial

## Case Description
The `propaneAbsorption` tutorial is modeled after the scenario described in [1], for which experimental and numerical data exist. It consists of a toluene film flowing down a vertical wall with a height of 0.1 m and a width of 0.05 m.
