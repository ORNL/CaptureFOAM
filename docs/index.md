# CaptureFOAM v1.0 User Guide
CaptureFOAM is a free software package released by Oak Ridge National Laboratory for efficient simulations of direct air capture or other gas/film mass transfer processes. It is built within the [OpenFOAM](https://www.openfoam.com/) computational fluid dynamics (CFD) framework.
